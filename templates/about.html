About FreshMart

FreshMart is an online fruits and vegetables shopping platform built using Django. Users can browse products, add items to cart, place orders, and track order history.

This project was created as part of a Full Stack Web Development internship to demonstrate practical skills in backend, frontend, authentication, database handling, and deployment readiness.

FreshMart is also inspired by helping local fruit & vegetable vendors grow digitally.
